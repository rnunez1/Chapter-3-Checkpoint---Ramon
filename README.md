# My Travel Blog

A personal travel blog built for my Website Development class.

## About This Project
This site is built one checkpoint at a time to practice HTML and CSS. It uses
semantic HTML5 elements and an external stylesheet.

## Files
- `index.html`: the homepage (header, navigation, article, and footer)
- `styles.css`: the external stylesheet linked to the homepage
- `about.html`: About page (optional, keeps the nav link working)
- `destinations.html`: Destinations page (optional, keeps the nav link working)

## Chapter 3 Progress
- **Checkpoint 1:** Linked an external stylesheet (`styles.css`) and styled the
  `body` with a light gray background, Arial font, and comfortable line spacing.
- **Checkpoint 2:** Added contextual selectors: `header nav a:hover` for link
  hover styling and `article h2` for heading styling inside articles.
